# Simple Interest Calculator

A Bash-based Simple Interest Calculator that calculates simple interest using the principal amount, rate of interest, and time period provided by the user.

## Project Description

This project is a simple command-line calculator written in Bash. It takes three inputs from the user:

- Principal amount
- Rate of interest
- Time period

It then calculates the simple interest using the standard formula.

## Formula

$$\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$$

## Input

The calculator asks the user to enter:

1. **Principal amount**: The initial amount invested or borrowed.
2. **Rate of interest**: Annual interest rate (percentage).
3. **Time period**: Duration in years.

## Output

The calculator displays:
- Calculated Simple Interest
- Total Amount ($\text{Principal} + \text{Interest}$)

## Technologies Used

- **Bash**
- **Shell Scripting**

## How It Works

The user provides the principal amount, rate of interest, and time period. The Bash script applies the simple interest formula and displays the result.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/aaryanbangale2306/Simple-interest-calculator-.git
   cd Simple-interest-calculator-
   ```

2. Give execute permissions to the script:
   ```bash
   chmod +x simple-interest.sh
   ```

3. Run the script:
   ```bash

   ```
